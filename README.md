# Book Hive 📚

A web-based book exchange platform for university students built with HTML, CSS, Bootstrap, JavaScript, and PHP.

## Features
- User Authentication (Signup/Login)
- List books with images
- Browse available books (Grid View)
- Edit/Delete your own listed books
- Contact form
- Gmail integration for book exchange

## Tech Stack
- **Frontend:** HTML, CSS, Bootstrap, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## Setup Instructions
1. Clone this repository
2. Import the database (see database folder)
3. Configure `connection.php` with your database credentials
4. Run on XAMPP/WAMP/local server
